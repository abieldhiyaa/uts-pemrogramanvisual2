# Prompt Eksekusi Awal — Front-end PPDB

Anda adalah implementer senior React, Vite, Tailwind CSS, dan UI/UX. Mulai proyek dari file SOT yang tersedia. Baca `AGENTS.md`, `docs/PRD.md`, `docs/UI-GUIDELINE.md`, dan `docs/IMPLEMENTATION_PLAN.md` sebelum coding.

## Tugas
Bangun prototype front-end Sistem Informasi Pendaftaran Peserta Didik Baru pada PAUD Qurrota A'yun berbasis React + Vite + Tailwind CSS dengan data dummy.

## Wajib tersedia
- Portal publik: beranda/informasi PPDB, persyaratan, alur, CTA.
- Form pendaftaran bertahap: data anak, data orang tua/wali, unggah dokumen demo.
- Nomor pendaftaran otomatis dan bukti pendaftaran yang dapat dicetak.
- Cek status pendaftaran.
- Login admin demo, dashboard statistik, tabel pendaftar, pencarian/filter.
- Detail verifikasi, checklist dokumen demo, dan status: Menunggu verifikasi, Perlu perbaikan, Diterima, Ditolak.
- Pengelolaan informasi PPDB.
- Laporan pendaftar yang dapat dicetak/disimpan sebagai PDF melalui browser.
- Logout kembali ke portal publik.
- Desain responsif, modern, bersih, dengan palet hijau muda, hijau tua, dan putih.

## Batasan
- Front-end saja; jangan membuat backend, database, API, pembayaran, presensi, pembelajaran, notifikasi, atau fitur lain di luar scope.
- Data bersifat dummy dan state demo.
- Jangan menyatakan autentikasi atau unggah dokumen sebagai fitur produksi.
- Jangan menambah paket kecuali dibutuhkan dan jelaskan alasannya.
- Semua teks antarmuka Bahasa Indonesia.

## Urutan kerja
1. Audit struktur proyek dan baca seluruh SOT.
2. Buat fondasi React/Vite/Tailwind.
3. Implementasikan portal publik dan form.
4. Implementasikan cek status dan bukti pendaftaran.
5. Implementasikan portal admin.
6. Uji semua alur dan responsivitas.
7. Jalankan `npm run build`, perbaiki error, lalu rangkum hasil.

## Keluaran akhir
- Kode sumber yang bisa dijalankan.
- README dengan langkah instalasi dan akun demo.
- Daftar fitur yang selesai dan pengujian yang benar-benar dijalankan.
- Daftar keterbatasan yang masih ada.
Jangan berhenti pada mockup statis: setiap tombol utama harus memiliki aksi demo yang masuk akal. Jangan mengerjakan hal di luar konsep.
